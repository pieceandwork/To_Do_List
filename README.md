# 📝 To-Do List (Список задач)

Простой и удобный консольный менеджер задач на Python. Позволяет добавлять, удалять и отмечать выполненные задачи. Поддерживает два языка (RU / EN) и сохраняет данные в JSON.

## ✨ Особенности
- ➕ **Добавление задач**: легко добавляйте новые дела.
- ✅ **Отметка выполнения**: ставьте галочки для выполненных задач.
- 🗑️ **Удаление**: удаляйте ненужные записи.
- 💾 **Сохранение данных**: все задачи сохраняются в `data_base.json`.
- 🎨 **Цветной интерфейс**: используется библиотека `Colorama` для красивого вывода в консоль.
- 🔔 **Уведомления**: оповещения через `plyer`.
- 🌍 **Два языка**: версии на русском (`To_Do_Ru.py`) и английском (`To_Do_Eng.py`).

## 🛠 Стек
- Python 3.x
- `colorama`
- `plyer`
- JSON

## 🔗 Установка

1. Клонируй репозиторий:
```bash
git clone https://github.com/pieceandwork/To_Do_List.git
cd To_Do_List
```
2. Создай виртуальное окружение:
```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
source .venv/bin/activate # Linux / macOS
```
3. Установи зависимости:
```bash
pip install -r requirements.txt
```
4. Запусти игру (русская версия):
```bash
python To_Do_Ru.py
```

# English Version
# 📝 To-Do List

A simple and convenient console task manager built with Python. Allows you to add, delete, and mark tasks as completed. Supports two languages (RU / EN) and saves data to JSON.

## ✨ Features
- ➕ **Add tasks**: easily add new tasks.
- ✅ **Mark as completed**: check off finished tasks.
- 🗑️ **Delete**: remove unnecessary tasks.
- 💾 **Data saving**: all tasks are saved to `data_base.json`.
- 🎨 **Colorful interface**: uses `Colorama` library for pretty console output.
- 🔔 **Notifications**: notifications via `plyer`.
- 🌍 **Two languages**: versions in Russian (`To_Do_Ru.py`) and English (`To_Do_Eng.py`).

## 🛠 Stack
- Python 3.x
- `colorama`
- `plyer`
- JSON

## 🔗 Installation

1. Clone the repository:
```bash
git clone https://github.com/pieceandwork/To_Do_List.git
cd To_Do_List
```
2. Create a virtual environment (optional):
```bash

.venv\Scripts\activate  # Windows
source .venv/bin/activate # Linux / macOS
```
